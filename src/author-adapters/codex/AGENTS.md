# Interactive Missions Authoring Workspace

This folder is an Interactive Missions marketplace authoring workspace.

Use the native Codex skills installed under `.codex/skills/`:

- `$create-tutor-mission` to turn a mission brief into mission content.
- `$qa-mission` to review a completed mission.
- `$maintain-missions` to maintain the marketplace framework.

Read `docs/1-index.md` before changing mission content. Keep draft missions under `marketplace/missions/`. Set the `source_url` TODO in `marketplace/manifest.yaml` before publishing or registering the marketplace.
